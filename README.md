# Orphan Planets 🪐

Orphan Planets is a modification for the Universe Sandbox that adds rogue planets to the simulation
- free—drifting worlds that do not revolve
around a star, but wander around the galaxy alone.

## What's inside

- Collection of real planetary mass objects: PSO J318.5-22,
 SIMP J013656+0933, WISE 0855-0714 and others;
- precisely adjusted parameters: radius, mass, temperature, spectral class;
- the ability to add any object to an existing system or simulation.

## Installation

1. Download the latest Zip file.
2. Copy the mod files to the custom objects folder Universe Sandbox.
3. Start the game and the objects will appear in the list of user objects.

## Compatibility

Universe Sandbox 36.2.2
